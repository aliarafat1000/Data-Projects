# 📊 Sales Analysis Dashboard for Retail Outlets

![blinkit_dashboard](https://github.com/user-attachments/assets/4707159b-5f86-47c4-870f-690d3b7248f4)



## 🎯 Objective and Goal

The goal of this project was to develop a detailed **Sales Analysis Dashboard** for retail outlets to help stakeholders understand sales performance across various dimensions such as outlet types, item categories, outlet sizes, and locations.

Key objectives:
- **Analyze sales trends** by outlet type, size, and location.
- Identify **top-performing product categories**.
- Visualize the impact of low-fat vs. regular products on sales.
- Provide actionable insights using KPIs.

---

## 🏆 KPI Requirements

1. **Total Sales**: `$1.20M`
2. **Number of Items Sold**: `8,523`
3. **Average Sales**: `$141`
4. **Average Customer Rating**: `4.0`

## 📜 Project Description

This project provides a comprehensive overview of sales data for a retail business using **Excel-based visualizations**.

### Key Features:
1. **Sales by Outlet Type**:
   - Supermarkets dominate sales with `$788K`.
   - Grocery stores account for `$152K`.
2. **Impact of Outlet Size**:
   - Medium-sized outlets contribute `42%` of total sales.
3. **Product Categories**:
   - **Fruits and Vegetables** lead with `$178K`.
   - **Snack Foods** follow with `$175K`.
4. **Low-Fat vs. Regular Products**:
   - Low-fat products contribute `64.6%` of total sales.
   - Regular products make up `35.4%`.
5. **Trends by Year**:
   - Sales peaked in `2018` at `$205K`.

### Dashboard Features:
- 📈 **Yearly Trends**: Visualize growth or decline in sales across years.
- 🛍️ **Product Performance**: See which items sell the most.
- 📍 **Location and Outlet Size Impact**: Discover regional and size-based trends.
- 🥗 **Low-Fat vs. Regular Sales Analysis**: Compare consumer preferences.
